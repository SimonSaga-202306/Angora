# 宪法第 2 条：用户信息、变化和北京时间

## 用户文字摘录

> 2 我发的所有信息（内容，要求，变更啥的），所有的！ everything都要入库进行记录
>
> 一定要注意所有信息的记录时间戳和变化，仓库都要有相关记录
>
> 注意所有时间戳要以北京时间为准，[https://time.is/Beijing](https://time.is/Beijing)

摘自[本轮用户消息单条人工转存](../inbox/user-messages/constitution-request-0001.txt)；不是平台协议原始字节证明。

## 执行

- 每条可见用户消息单独捕获，内容、要求、修改和撤回均保留；一条助手消息也单独留存，不与其他消息拼接。修改／纠错新增记录并链接旧记录，不静默改写。
- 派生时间使用 `Asia/Shanghai`（现代北京时间 UTC+08:00），显示 ISO 8601 偏移；若来源原始文件包含其他时区，原文件和原始时间字段不改写，同时另存北京时间转换与来源。
- 分别标明事件发生／消息收发时间、入库观察时间、时间来源和精度。真实收发时间不在可见上下文内时为未知，不用现在的墙钟代填。
- 参考 [time.is 北京](https://time.is/Beijing)；网页显示时间、本机系统钟和会话提供的日期若冲突，分别留证并标记未校准，不把动态网页或 `Your time is exact` 当成对沙箱、用户设备或过去消息时间的证明。
- 重置前两次网页工具文字和直接请求失败是彼此独立观察；完整文件随重置丢失，不能自动回填历史消息时间，详见独立问题记录。
