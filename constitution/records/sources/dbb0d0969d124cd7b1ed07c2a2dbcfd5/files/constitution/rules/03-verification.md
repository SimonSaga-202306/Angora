# 宪法第 3 条：交叉检查、抽检及其他检查

## 用户文字摘录

> 3 信息都要进行交叉检查 抽检 各个方法来检查，确保都OK 都入库 没有遗漏和错误

摘自[本轮用户消息单条人工转存](../inbox/user-messages/constitution-request-0001.txt)；不是平台协议原始字节证明。

## 执行

- 读取前先列本轮实际范围及路径、大小；逐项读取并记录哈希与结果，对原件、版本、副本、清单、Git 暂存对象以及已保存失败做交叉核验，注明抽样或全量的分母。
- 用 `snapshot` 先固化记录文件范围再计算 SHA-256；用 `verify --snapshot ID` 检查载荷、元数据、缺失、变化和额外文件。新记录不替换旧快照；把快照固定在 Git 中。
- 抽检选择代表性样本（如不同格式、失败、同哈希不同来源、路径和边界值），保存抽样标准与结果；单元测试和手工检查互补。发现错误后独立记录首次失败、修复和复测。
- 哈希只能验证指定字节相对指定清单是否改变，不能证明资料完整、真实性、外部来源独立或未见消息已被保存；不得宣称绝对零遗漏、零错误。
