# 仓库宪法：所有工作区均适用

遵循更高优先级指令，并逐条执行 [`constitution/`](constitution/README.md) 的六条用户宪法。此文件不是平台自动采集器；每轮代理须主动检查和执行。

1. **永不擅自合并对话**：一条用户或助手消息一个记录；一份来源一个产物。相同内容、相同哈希、同名或疑似同一主体也不替代、覆盖或去重。只有用户主动明确要求的具体合并才可另建派生物，原始记录仍保留。摘要不能替代原文。
2. **逐条保存和版本**：将用户可见的每条新消息、要求、变更及助手消息独立存档；变更新增版本并关联旧记录，不静默修改。标注字节副本、平台可见文字或人工转录的保真度。平台未提供的消息、原始协议字节与实际收发时刻均为未知，不得编造；不要把内部系统消息或凭据写入仓库。
3. **北京时间与核验**：日期/时间展示为 `Asia/Shanghai`，保留原始来源时间，说明事件时间、记录时间、来源和精度。参考 https://time.is/Beijing ，不把未校准墙钟或动态页面当作消息时间。先列范围，再逐项读取，保存大小和哈希；交叉核验、抽检、记录失败与修复，明确检查范围及未知项。
4. **来源和问题**：在授权且不违反既有停项的前提下，逐个保存爬取的原始文件/响应体；无法阅读也先保存可取得字节，工具提取文本单独保存并标明不是原件。失败、未取得原件/块、大小限制和不可入库的内容在最终答复明确说明；重要不确定或授权冲突先问。不得保存凭据或绕过访问限制。
5. **防沙箱重置**：先看当前分支、远端、已跟踪修改和未跟踪文件；碰撞先列清单并验证可靠保护，才可快进。stash 可能随重置消失，不得依赖它作为唯一备份，不盲目覆盖或 pop/drop。只在当前分支提交推送并核远端。用 `python3 tools/constitution_ledger.py recovery-plan` 获取只读检查，仍需人工核验忽略文件和远端最新状态。
6. **复杂工作**：估量、拆解并持续做实质性工作，平衡实现和检查，不因几分钟无故停止；不靠睡眠或空转凑时间。确实完成或遇到需用户决定的阻碍时如实说明。

本仓库公开；用户已在知情后选择允许本轮及后续对话逐条公开，详见 [`publication-consent.md`](constitution/policies/publication-consent.md)。这不授权公开凭据、访问关闭应用或重启 PASS。既有约束见 [`preexisting-boundaries.md`](constitution/policies/preexisting-boundaries.md)。
