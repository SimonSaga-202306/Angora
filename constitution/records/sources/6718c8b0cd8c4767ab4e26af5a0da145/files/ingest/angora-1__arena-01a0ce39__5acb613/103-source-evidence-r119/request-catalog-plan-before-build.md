# 逐请求目录与派生清单计划

在已有计划、各单独搜索文件、各块／错误与元数据基础上，编制独立的请求清单。Q01–Q40 各列一次搜索，重复检索也单独保留；P01–P17 每个实际请求块单列，A01–A05 与 time.is T01 单列。每项生成一个派生 request manifest 与总索引，引用已存在的人工转录、保护性摘录或错误元数据，不把多个来源合成一个原文；清单生成后逐项入账。

注意 P02 块 5–7 原来只在一个保护性观察 JSON 中分别记述，派生三份单请求元数据并标注同一观察源，不能冒称保存了各完整响应；P09 块 2 只有元数据，P12 是基于 P01 的手工重构。Q13–Q27 由并行响应人工对应，若缺自动对照则记归属尚未独立证明；Q28–Q40 为逐次单独请求。重复检索不算独立报告。每次事件真实发生时间未知；不从本机墙钟或自标日期倒填。
