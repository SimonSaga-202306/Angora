## 限定范围及顺序

本轮研究 Angora 已有订单的**固件、设备型号和售后可追溯性**；不联系客户，不重启已 PASS 的旧账、未成交事项、旧 RFQ/RFP、INFO.rar 解压或其他 PASS 项。没有新抓外网，也没有运行、安装或解包固件。

**顺序披露**：入场探索时，在正式限定清单之前已预读容器报告、原包元数据、2026 回复抽取和旧分析，并搜索部分文件名/聊天文字，因此没有完全做到“任何接触材料之前先列清单”。随后分别列出正式范围的路径和字节数，再重新完整读取这些现存本地产物的每一个字节并计算各自 SHA-256；四个 `scope-before-read` 文件指的是**正式全量字节复核之前**，不是首次探索性阅读之前。旧分析仅作纠错上下文，不计入 4,903 项输入。

## 固件树的核对与盲区

- 原 `.bin` 在本地源路径不可用，原源仓 commit 也不在当前本地 Git 对象库。历史 [元数据](../03-binary-meta/3rd%20order%20176台2光16电%20L2%20PoE/lite-hotfix-7.3.13.bin.meta.json)记 62,289,840 bytes / SHA-256 `7fe48e24a87cdd731f9f238f3607ae9b1d41cb46b20ba8b64fa6feb52e5a70d4`；这是历史记录，**不是本轮重算原件**。历史 [CONTAINER.md](../05-nontext-content/firmware/3rd%20order%20176台2光16电%20L2%20PoE/lite-hotfix-7.3.13.bin/CONTAINER.md)描述容器分层和当时的 MD5 比对，也不是本轮独立复验或来源真实性证明。
- 本轮解析既有 `rootfs-FILELIST.tsv`：9,655 行，6,999 普通文件、627 目录、2,029 符号链接。4,881 个现存 `rootfs-text/` 路径与 2,118 个 `rootfs-binary-index.tsv` 路径不重叠，并覆盖清单中 6,999 个文件名，大小逐项相符；后者记录的二进制大小总计 118,280,374 bytes。**2,118 项只是历史索引，本轮没有这些二进制的载荷来重算其哈希。**
- 4,881 个现存路径均由当前 Git index 跟踪，且本轮读取的 SHA-256 与对应现有 Git blob 字节逐项一致；这是**当前 Git blob 与当前本地派生文件一致**，不是该派生文件与缺失原固件逐字节一致的独立证明。目录历史上称 `rootfs-text`，其中 95 文件为空、392 个无法按 UTF-8 解码、2 个含 NUL；这些计数可重叠，不能把其等同全部可读的普通文本。
- 对这 4,881 个本地文件按 ASCII 不区分大小写做完整精确字节搜索：`ANW-2116-PG`、`STI-21616DGGPM`、`LT-IS6318GP-2GX16GT` 各零个路径命中。只意味着**所列字符串在现存文本派生树的精确扫描中未命中**；不覆盖其他写法、历史二进制、符号链接目标或缺失原包，也不证明设备不兼容。
- 包内存在具 16 个 `1000_T`、2 个 `1000_X` 配置项的配置文件，但同端口形态不等于指定 SKU 或硬件版本匹配。另一个配置文件的路径命名与内部 `name` 字段不一致，可能是别名、复用或配置问题，原因未知；不可凭文件名刷机。

## OCR 和日期

聊天的 `2026-07-08 13:34` 来自既有 OCR 对齐档；该卡片写同名 `.bin` 与 `59.4M`。历史元数据的 62,289,840 bytes 约为 59.404 MiB，与按一位小数显示 59.4 的数值相容；但聊天卡片未声明单位换算、没有 SHA，不能证明同一文件。对齐 JSONL 将消息归为 Simon，另一版 `wechat-2026.md` 将相同片段归为 Taylan；**发件人及对齐须原截图/聊天记录复核**，原截图本轮未取得。文件卡片和“请转交”不等于最终收件、集成、安装、修复或验收。

会话工作日期按给定的 **2026-10-26 UTC**；执行环境时钟显示 2026-11-19，后者仅用于记录相对工作间隔。用户没有指定以 10 月 26 日截断资料；动态网页的实际采集日未知时不得从文件名或不一致的环境时钟倒填。文件内标注时间是材料里的文字，不等于独立认证的构建时间。
