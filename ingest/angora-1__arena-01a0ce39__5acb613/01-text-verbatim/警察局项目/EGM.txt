3.3 现场网络交换机 (Field Network Switch)
3.3.1. 类型： 必须为工业型交换机。
3.3.2. 端口规格：
至少具备 8 个 10/100/1000 Ethernet 端口。
至少具备 2 个 1000 Base-X SFP 端口。
SFP 端口需预装同品牌或制造商认可的兼容模块，支持至少 1 公里传输距离。
3.3.3. 工作温度： 范围至少为 -40°C 至 +60°C。
3.3.4. 工作湿度： 相对湿度环境支持 10% 至 95%。
3.3.5. 冷却方式： 采用无风扇冷却，不得有活动部件冷却系统。
3.3.6. 防护等级： 防护等级至少为 IP20。
3.3.7. 故障保护： 支持故障保护报警继电器输出。
3.3.8. 配件： 每个 SFP 端口需配备至少 1 米长的兼容纤维跳线。
3.3.9. 运行模式： 所有端口必须以非阻塞模式工作。
3.3.10. MAC 地址： 至少支持 8,000 个 MAC 地址。
3.3.11. 优先级队列： 具备 4 个优先级队列。
3.3.12. 管理协议： 支持 RMON 和 SNMP v1/v2/v3；可通过 Telnet、控制台端口（Console）和 Web 界面管理。
3.3.13. 二层协议： 支持 ICMP 和 IGMP snooping。
3.3.14. VLAN 与环路协议： 支持 IEEE 802.1Q VLAN、MSTP (IEEE 802.1s)、x-ring 或等效协议、VLAN 标记/中继（Trunking）。
3.3.15. 优先级标准： 支持 IEEE 802.1p 优先级划分和 ToS 标准。
3.3.16. 端口安全： 可基于 MAC 地址实现端口安全。
3.3.17. 访问控制： 支持 IEEE 802.1x 基于端口的网络访问控制。
3.3.18. 端口镜像： 支持端口镜像功能。
3.3.19. PoE 供电： 每个以太网口均应支持 IEEE 802.3af (PoE) 和/或 IEEE 802.3at (PoE+)。
3.3.20. 链路聚合： 支持 LACP (IEEE 802.3ad)，可将多个端口聚合为单个虚拟中继端口。
3.3.21. 网络协议： 支持 IPv6、VLAN 接口 IP 地址分配及流量管理。
3.3.22. 统一性： 所有现场网络交换机必须为同一品牌和型号。


3.4 室内网络交换机 (Indoor Network Switch)
3.4.1. 端口规格：
至少具备 24 个 10/100/1000 Gigabit 以太网口。
至少具备 4 个 1000 Base-X SFP 端口，并预装支持至少 10 公里的兼容模块。
3.4.2. 自协商： 所有 Base-TX 端口支持自动协商、全双工、半双工及激活设置。
3.4.3. PoE 供电： 所有 Base-TX 端口支持 IEEE 802.3af/at (PoE/PoE+)。
3.4.4. 工作温度： 范围至少为 0°C 至 +45°C。
3.4.5. 工作湿度： 相对湿度支持 10% 至 85%。
3.4.6. 交换容量： 背板带宽至少为 56 Gbps。
3.4.7. 转发性能： 包转发速率至少为 41.7 Mpps。
3.4.8. MAC 地址： 表容量至少支持 16,000 个 MAC 地址。
3.4.9. 生成树： 支持 IEEE 802.1d 生成树协议。
3.4.10. 安全特性： 支持 BPDU 保护（BPDU guard）功能。
3.4.11. 流量控制： 支持 IEEE 802.3x 流量控制。
3.4.12. 链路聚合标准： 支持 IEEE 802.3ad 标准。
3.4.13. 聚合配置： 至少可配置 4 个中继组（Trunk 或 LAG），每组至少包含 8 个端口。
3.4.14. VLAN 能力： 支持 IEEE 802.1Q；支持至少 4K VLAN ID 和至少 1,000 个 VLAN。
3.4.15. 巨型帧： 支持至少 9,000 字节的 Jumbo frames。
3.4.16. 优先级标准： 支持 IEEE 802.1p 标准。
3.4.17. 队列操作： 可基于二、三、四层协议类型进行队列操作。
3.4.18. QoS 服务： 支持 DSCP 标记及基于 IP 的 QoS。
3.4.19. 速率限制： 支持端口速率限制（Port Rate Limiting）。
3.4.20. 调度机制： 每个端口支持至少 4 个优先级队列，支持 WRR（加权轮询）或等效协议。
3.4.21. 组播： 支持 IGMP Snooping v1 和 v2。
3.4.22. 组播组： 至少可配置 255 个组播组。
3.4.23. 访问控制列表 (ACL)： 可基于二层 MAC、三层 IP 和四层协议信息创建 ACL。
3.4.24. ACL 规则数： 至少可配置 200 条访问控制规则。
3.4.25. 认证： 支持 IEEE 802.1x 基于端口和基于 MAC 的认证。
3.4.26. 动态 VLAN： 支持通过 802.1x 动态分配 VLAN，并支持 Guest VLAN。
3.4.27. 端口镜像： 支持端口镜像用于流量分析。
3.4.28. 路由能力： 支持 IPv4 静态路由。
3.4.29. 安全访问： 支持 SSH。
3.4.30. 管理协议： 支持 SNMP v1/v2/v3；可通过 Console 端口和 Web 浏览器管理。
3.4.31. RMON： 支持 RMON 4 组（统计、历史、告警和事件）。
3.4.32. DHCP 特性： 支持 DHCP Relay、DHCP Snooping 和 DHCP Option 82。
3.4.33. 端口安全： 支持端口安全功能。
3.4.34. 发现协议： 支持 IEEE 802.1ab LLDP。
3.4.35. 日志： 支持 SYSLOG。
3.4.36. 网络协议： 支持 IPv6。
3.4.37. 认证服务： 支持 Radius 和 TACACS+。
3.4.38. 固件版本： 必须提供最新且最先进的固件。
3.4.39. 内存规格： 至少具备 128 MB RAM 和 16 MB 闪存。
3.4.40. 配置与更新： 可存储多个配置文件，支持通过 TFTP 更新固件。
3.4.41. 许可： 报价中必须包含所有指定功能运行所需的全部许可证。
3.4.42. 交付配件： 需随交换机一同交付电源线、机柜安装配件和 CAT6 线缆。
3.4.43. 时间同步： 支持 SNTP 或 NTP 以进行全网同步。
3.4.44. 统一性： 所有室内网络交换机必须为同一品牌和型号。
