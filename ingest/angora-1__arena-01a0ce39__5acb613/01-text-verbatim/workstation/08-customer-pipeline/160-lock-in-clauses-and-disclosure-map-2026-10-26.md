# r91 · 土耳其公共交换机标的的「锁死条款」—— 壁垒不在参数，在生态

- 轮次：**r91**（承接 r90 能源渠道）
- 日期：**2026-10-26**
- 主轴：r89 把"参数"逐条对完了（TTK 2.1/2.2/2.3），r90 找到了"成交价"。本轮问一个更狠的问题：**参数全过的机器，为什么还是进不去？** 答案在 **ETİ MADEN 的技术规格书**里 —— 一份把"生态锁定"写到极致的官方文本。

## 一、结论先行

1. **土耳其公共交换机标的的技术门槛分两层**：**第一层是数据表**（MTBF / 转发率 / 温度 —— r88/r89 已逐条对完），**第二层是生态**（同品牌、与现网设备堆叠、与客户已有网管软件兼容、进第三方 NAC 兼容矩阵、**光模块必须原厂**）。**第二层才是真正把我们挡在外面的那层**，而且它**从来不写在"技术参数"里，写在"其他事项"或"投标范围"里**。
2. **ETİ MADEN 的规格书是一份"排除法"范本**：全数交换机**必须同一品牌**、**必须在 Forescout 8.2 兼容矩阵内**、**SFP/GBIC 必须原厂（OEM 不接受）**、无线必须与现网 **Huawei AC6605** 完全兼容、有线必须被 **Huawei e-Sight** 纳管、48 口必须能与现网 **Huawei S5735-S48P4X 堆叠**。⇒ 这不是"买 44 台交换机"，这是"**买华为**"。
3. **⭐ 这条对我们最痛**：r89 把"**长距 SFP**"定为对 Angora 的第一卖点。**但在 ETİ MADEN 这类标里，第三方光模块被明文禁止** ⇒ **SFP 生意只能做"买方不要求原厂光模块"的那部分市场**，而且**必须由持证整机厂以"原厂"名义出货**。这不是推翻 r89，是给 r89 划出准确边界。
4. **渠道公示地图**（承 r90）：**Enerjisa 系（AYEDAŞ / Başkent / Toroslar）用网页表格**；**UEDAŞ 用"一标一 PDF"**（含 `İHALE ÜZERİNDE KALAN FİRMA` + `SÖZLEŞME TUTARI`，美元）；**OEDAŞ 用"编号+İncele"**。⇒ **21 家 EDAŞ 的信息开放度差异极大，但至少 5 家有可机器读取的结果页。**
5. **新工具**：**`TaahhütHaber` 每工作日一份 PDF 公报**，按组（A/AI/AIII/AXVI…）列出**当日 EKAP 全部结果与中标方**，且**专设 `BOTAŞ/TPAO - ETİ MADEN - TKİ - TTK` 组**。⇒ 这是继 EDAŞ 官网之后**第二条不需要 EKAP 账号的结果渠道**。⚠ 但本轮用它**仍未查到 TTK 两轮交换机标（2534053 / 2625016）的中标方** —— **第四次确认不可查**（因为两轮状态都是 `Geçmiş/İptal`，取消标不会产生结果公告）。

### 2.2 ⭐⭐⭐ 五条"锁死条款"（3.1 条原文，逐条翻译）

| 条款 | 原文要点 | 效果 |
|---|---|---|
| **a.** | 全部设备须为全新、未使用、**未发布 EOL/EOS 通告** | 排除清库存与二手 |

| **c.** | 随机提供的 **SFP/GBIC、XFP/SFP+ 必须为制造商原厂产品；OEM 产品不予接受** | **直接封死第三方光模块**（对 r89 的 SFP 论点划边界） |

| **e.** | 有线设备须与院内网管 **`Huawei E-Sight`** 完全兼容并受其管理 | 事实上 = 只买华为交换机 |
| **f.** | **48 口边缘交换机须能作为 stack 成员并入现网 `Huawei S5735-S48P4X`** | **决定性的排除条款**：非华为无法与华为堆叠 |
| **g.** | 铜/光纤跳线须同品牌（为保证系统与性能一致性） | 被动件也被绑定 |

### 2.3 第一层（数据表）也没放过
**Fiber Anahtar 24 Port** 的硬指标：**≥24×1Gb SFP + ≥8×1Gb 铜 + ≥4×10Gb XFP/SFP+**；随机 **2×10GBASE-LR 10 km + 12×1000BASE-LX 10 km** 光模块；**可堆叠 8 台、堆叠带宽 ≥40 Gbps**；**交换容量 ≥144 Gbps / 转发 ≥108 Mpps**；**≥4,000 VLAN ID / 1,000 活跃 VLAN**；**≥8K IPv4 路由表**；MSTP + PVST+；DHCPv6/SNMPv6/TFTPv6；SSHv2 + SFTP/SCP。
⇒ 注意：**108 Mpps / 144 Gbps** 这一档，**与 TTK 的 95.23 Mpps / 128 Gbps 是同一代 D-Link 家族的数字**（r88 已证 TTK 是 D-Link 指纹）⇒ **土耳其公共标的技术参数高度同源，几乎是"同一份模板换数字"**。
⇒ 而 **24×SFP + 8×铜 + 4×10G** 这种"光口为主"的形态，**Angora 有（`ANW-5713-24S8T6X`）**，我们**没有对位机**（我方以铜口 + 少量 SFP 为主）。

## 三、⭐ 对我们最痛的一条：**"原厂光模块"条款**

- r89 的结论：Angora 的 SFP 只有 550 m / 10 km 两档，**KGYS 要 70 km ⇒ 它必须外购 ⇒ 这是我能卖进去的东西**（我方 LX 成本 ≈25 RMB vs 土耳其零售 ≈1,485 TL）。
- **r91 的修正**：**只要标书写了"原厂光模块、OEM 不接受"（ETİ MADEN 3.1.c 原文）**，**这条生意就不存在** —— 因为买方要的是"**整机厂原厂**"标签，我方是模块厂，**必须以 Angora 的名义、Angora 的包装、Angora 的质保出货**，且 Angora 要为此承担兼容性责任。
⇒ **准确表述（替代 r89 的单线结论）**：
| 场景 | SFP 生意可否成立 |
|---|---|
| 标书明文「原厂光模块、OEM 不接受」 | **不可直接卖**；只能做 **Angora 的 ODM 供方**（隐形） |
| 标书只写「兼容、支持 XX 标准」 | **可卖**（作为独立报价项或备件） |
| 现网扩容/备件（非招标） | **可卖**（这是最快的现金流） |
⇒ **行动建议**：向 Angora 提的**不是"卖你 SFP"，而是"做你的 SFP 白牌线 + 你出原厂标签"** —— 这同时也解决了 r90 的 62443 / 原厂条款问题（**责任与标签都在本地持证方**）。

## 九、补录（同轮续做）：**Forescout 那道门其实也关着** + 21 家 EDAŞ 公示地图的真实覆盖率

### 9.1 ⚠ 自我修正：第六节第 3 条「Forescout 8.2 矩阵是唯一可解的生态门槛」—— **判定过乐观**

查 Forescout 官方文档后的事实：

- **`CounterACT Network Devices Compatibility Matrix`（有线交换机部分）只列了几家一级厂商**：**Cisco / HPE（含 ArubaOS-CX、ProCurve、Comware）/ Juniper / Avaya(Nortel) / Huawei / H3C / Alcatel / Arista / Brocade / Dell（OS10、DNOS 9.x、**SONiC**）/ Enterasys / Extreme（K6）/ Hirschmann-HiOS / DNI**。
- **`Switch Plugin` 的支持厂商清单同样是一级厂商集合**（Alcatel / Arista / Avaya / Brocade / Cisco / Dell / Enterasys / Extreme / H3C / HPE / Hirschmann / Huawei / Juniper / DNI 等）。
- **`Switch Vendor ACL Support` 表只有 15 行** —— 同样是这份一级厂商名单。

⇒ **`D-Link`、`Zyxel`、`PLANET`、`Angora(ANW)` 均不在上述任何一份清单里**。
⇒ **正确表述**：ETİ MADEN 的 b 条（"必须在 Forescout 8.2 矩阵内"）**不是一扇可以推开的门，而是又一道品牌筛** —— 它把"非一级厂商"整体排除，效果与 d/e/f 条（华为生态）叠加，**指向同一结论：这类标事实上是同品牌续购**。
⇒ **我方若要"进矩阵"**，需要 Forescout 官方（或其 SDK/插件层）为该 ODM 做验证并列入矩阵 —— **周期以季度计、且需要品牌方出面**，**不是我们这一层能单方面解决的**（是否可行，须先问 Angora 与 Forescout 土耳其代表处）。
⇒ **对销售话术的修正**：不要再说"我们能帮你进 Forescout 矩阵"；**改说"这类标只能守，不能攻；我们的战场在没写 NAC 兼容条款的标"**。
⚠ 本条的诚实边界：Forescout 文档中"products in these tables represent **a subset** of each vendor's portfolio, as it is impossible to test every available model"（原文）—— 即**矩阵本身也不是全型号覆盖**，但**厂商级覆盖仍是那十几家**。
