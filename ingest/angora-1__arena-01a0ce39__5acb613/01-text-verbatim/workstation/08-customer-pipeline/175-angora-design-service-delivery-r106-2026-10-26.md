# r106 · Angora 设计、服务和交付边界：从宣传菜单到可证事实

> **结论先行**：Angora 将设计服务、专业服务、支持和培训作为公开能力介绍；但“可提供”不是“某项目已经设计、制造、授课或兑现 SLA”。既有客户文书体现了品牌与 GUI 等定制要求及回复，不足以证明这些工作由官网 OEM/ODM 服务完成，或某台实机已经按文书交付。

## 一、OEM/ODM：宣传的是服务范围，不是全部产品的来源证明

[Angora 土文设计服务网页的工具可见文字](../../../49-source-evidence-r106-2026-10-26/external-visible/www.angoranetworks.com/ozgun-tasarim-oem-odm-hizmeti/index.tr.extracted.md)写有 `100% Yerli Tasarım`，并说 Angora 设计服务由土耳其工程师在土耳其提供；还描述 Intel／ARM 平台相关主板、从电子设计到实体外壳、以及定制操作系统等能力。网站文字是**厂商自述的服务品类和范围**。

| 厂商可见文字 | 它能支持的内部记录 | 不能由此推出 |
|---|---|---|
| 土耳其工程师在土耳其提供设计服务、标题“100% 本国设计” | 厂商对服务地点和设计身份的说法。 | 所有零部件均本地制造、全部产品均由该团队设计、任何具体认证已经取得。 |
| 从基于 Intel／ARM 的 IoT 板卡到高端服务器的设计范围；页面提及合作 | 厂商声称的设计平台／服务跨度。 | 已为某客户交付该范围内每种产品；相关权利、授权及双方合作状态均已独立核实。 |
| 从电子设计到外壳的完整硬件 | 厂商说可提供设计到成品硬件的方案。 | 自有工厂、全部自制 PCB、元器件清单、产能或具体设备的生产地。 |
| 与硬件兼容、按需求简化的定制操作系统 | 厂商说可提供定制系统。 | 某命名系统的源码或知识产权归属、第三方许可证、适配效果或客户验收。 |

上述四行属于同一厂家页面，不是四份独立实验或已完成合同。[r94 旧档](163-angora-corporate-chronicle-2016-2026-2026-10-26.md)把“服务可覆盖”写成“交付含”，本轮**修正为服务声明**；旧档另将全部某产品线归为“100% 买主板＋自有系统”，仅凭处理器或支持软件名称不能证明全部 BOM、制造环节及系统权属。本轮不否认已有的特定交易资料，也不重查历史财务。

### 2023 年访谈：经营思路与已实现结果不能混算

[ICT Media 网页文字](../../../49-source-evidence-r106-2026-10-26/external-visible/ictmedia.com.tr/haber/yerli-bir-ureticiye-verilebilecek-en-buyuk-destek-onun-urunlerini-kullanmaktir/index.tr.extracted.md)显示 `2023-06-08 15:07`，刊载对 Angora 总经理 Levent Kılıç 的访谈摘要；r94 已提及这次访谈，**不是本轮首次发现**。本轮四个工具块完整保存、[按原文逐项定位](../../../49-source-evidence-r106-2026-10-26/interview-claim-matrix.csv)：

- 他称 Angora 以自有品牌销售，项目数量和规模足够时也能提供 OEM；没有给出最低数量、已完成项目名单或报价。本轮不追问阶梯报价。
- 他把业务分为设计、生产、营销和销售，并称开始把设计和生产环节向技术园区迁移；这是受访者对当时业务的陈述，不证明整个工厂已搬迁、园区地址或当前产能。
- 他声称产品的知识产权属于公司，并描述产品化时关注可订购、测试与文档。媒体刊载的企业自述不是逐项专利、源码许可、BOM 或每个型号均已完成测试的独立证明。
- 他曾以“本年度 5,000 台、首年 3,000–5,000 台”说明规模规划思路；这是叙述中的**规划例子**，不是已实现销量、出货、营业收入或市场统计。本轮不做历史财务对账。
- 他介绍瘦客户端方案由管理、终端和终端软件组成；另在回答标准问题时称设备的电气测试由土耳其认可实验室进行。这是两个不同段落，均为访谈自述，不能自动把测试归到瘦客户端。本轮未取得具体方案合同、实验室报告或证书，不能据此宣称某项目交付或某型号通过认证。

媒体是另一发布方，但上述内容仍来自 Angora 管理者，并非独立核验；页面的后续推荐栏目含晚于会话日期的日期，不当作 2023 访谈正文或已核实的历史快照。

## 二、专业服务和支持：服务选项不是无条件 SLA

本轮[土文服务页](../../../49-source-evidence-r106-2026-10-26/external-visible/www.angoranetworks.com/hizmetlerimiz/index.tr.extracted.md)与 r97 已存[英文服务页文字](../../../15-source-evidence-r97-2026-10-26/www.angoranetworks.com/our-services-2/index.en.extracted.md)分别保存。两个文本都把 Angora 团队和解决方案伙伴放在提供服务的叙述中，并列项目管理、HLD／LLD、安装部署、网络分析测试及网络／安全外包等；这些是服务菜单，不证明 Angora 一家公司独立完成所有环节或已经实施某项目。

| 类别 | 页面字面内容 | 不能自行补出的合同条件 |
|---|---|---|
| 硬件支持：标准 | `Best Effort`、15 天内的表述。 | 起算事件、响应／修复／更换分别指什么，以及是否存在必达 SLA。 |
| 硬件支持：更换 | 下一天更换、4 小时更换；页面均注明针对 Angora 产品。 | 覆盖地区、备件库存、购买等级、节假日、故障类型及全部客户均适用。 |
| 软件支持 | 年度维护合同；`5x8` 与 `7x24` 选项。 | 时区、响应窗口、升级权利、支持对象、实际支付或可用性保证。 |

不能把“4 小时更换”说成全年所有地区自动响应、把 7×24 选项说成设备 100% 在线，也不能把服务名称当作已签合同。[21 组可见条目](../../../49-source-evidence-r106-2026-10-26/services-cross-language-items.csv)逐行保留英／土文本、来源及边界；两页同属一个发布方，不构成独立履约证明。

## 四、把历史定制文书放回其本来证据层

- [2024 文档既存文字层](../../../02-extracted/2nd%20order%20sample%202层10G%2016口%202光8管理/Angora-Replies_2024.10.23.docx.extracted.md)有型号／Logo、照片及 Web GUI 相关的提议或回复；文字层部分说话人不可靠，内嵌图片和原始 DOCX 本轮未重取。文字说“已添加”或“附图”，不等于独立确认实物或最终批准。
- [2025 文档既存文字层](../../../02-extracted/3rd%20order%20176台2光16电%20L2%20PoE/Info%20to%20be%20provided-Angora.docx.extracted.md)另列 Logo、型号、标签和 Web GUI 产品号的要求／回复。这是另一份独立记录，不与前一份合并为同一设备；不能认定它由官网 OEM/ODM 服务完成、已交付或已验收。
- 两份文档的[17 条选定原行](../../../49-source-evidence-r106-2026-10-26/historical-design-text-lines.csv)只用于说明品牌与界面定制的**文书层次**，不是供应链尽调、产品来源或标识合规意见；不向客户追问旧单。

可把证据层按“网页提供服务 → 个案需求／回复 → 双方签署范围 → 设计版本／授权 → 出厂资料 → 实物／测试 → 交付验收”分别建字段；缺失就记未知，不能把任一层自动升级成下一层。这里并不安排新的项目接触或现场工作。

## 五、时间、覆盖及具名纠错

- **修正／取代 r94 的绝对化生产判断**：其“以进口白牌为底座”和“某产品线 100% 买主板＋自有系统”不能无条件应用于全部产品；官网设计服务宣称也不能反过来证明全部自研。按型号、配置和证据单独记录。
- **修正／取代 r94 把 81 地理覆盖与 6 个已识别主体直接当矛盾、并推定渠道密度极低**：地域覆盖与主体数量不是同一个分母。这里只纠正逻辑，既不证明也不否认任何覆盖或履约情况；此前 r95 已撤回“6 家即全部渠道”。
- **限定 r94 的 OEM/ODM 联系入口及主动联系建议**：本轮工具可见文字只证实一般介绍和支持链接，未证专用受理路径；这不证明原始 HTML 没有表单，也不代表旧网页当时没有入口。本轮不提交表单、不发消息。
- **修正／取代 r40 保存的索引中“官网没有任何页面改动”**：两份旧 TSV 中相关页面 ID 的 `date`／`modified` 字段一致，只能证明两份保存文本的字段相同，不证明正文、整站或中间历史未变。r104 已指出该旧 TSV 头写 24 但现存数据行是 25；原表不改。[逐行哈希](../../../49-source-evidence-r106-2026-10-26/cms-relevant-page-rows.csv)保留旧字段，不重连 CMS。

两份旧 TSV 对以下两条页面记录的字段文字相同，详见[字段对照](../../../49-source-evidence-r106-2026-10-26/cms-service-fields-comparison.csv)与[文件行数核对](../../../49-source-evidence-r106-2026-10-26/cms-saved-row-counts.csv)：

| 旧表页面 ID | `date` 字面值 | `modified` 字面值 |
|---|---|---|
| OEM/ODM，1152 | `2022-12-03T21:01:04` | `2022-12-03T21:11:17` |
| 服务页，275 | `2020-12-31T17:49:31` | `2021-05-02T23:48:43` |

本会话提供日期 **2026-10-26 UTC**，执行环境时钟却显示 **2026-11-19 UTC**；目录日期不能单独证明旧网页的采集日期。旧 TSV 字段不等于产品上市日、服务正式启动日或现行合同期限。

**全量读取完成（本轮限定本地清单）：20/20 个不同路径、179,252 bytes；其中三个旧文及一个旧索引在本轮较早的安全清单下已先列并读过，之后才纳入专题或比较清单。** 另 4/4 个 URL 的 7/7 工具块按 URL 分别转存，共 41,836 bytes；其中 1 个关于页因意外包含已停主体的图标链接而隔离、**不用作结论**，另 2 个厂商服务页和 1 篇媒体访谈可分析。旧网管页也因同样原因只记入读取清单而排除结论。人工转存未自动逐字与工具响应比对，不等于原始 HTML；未穷尽 Angora 的全部商业信息。
