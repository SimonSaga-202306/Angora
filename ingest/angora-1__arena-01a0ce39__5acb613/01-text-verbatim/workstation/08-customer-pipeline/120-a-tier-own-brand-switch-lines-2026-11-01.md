## 〇、一句话结论

> 🛑 **r52 修正（取代 r51 的横切结论）**：本文「A 档四家自有线 **0 款 2.5G**」对 `#2/#3/#4/#146` **仍字面成立**，但由此推出的 **「2.5G / bt / 云 = A 档通吃差异化」已被推翻** —— `A/001` Telkolink/GelecekBT **不在 r51 样本内**，其 **CLR Networks 线有完整 2.5G 产品线**（5/8/16/24 口，含 PoE 与 L3，最高 **24×2.5G PoE + 6×10G SFP L3**，另有 **24×2.5G + 100G 上联**），**bt（Tip3 60W ×3 / Tip4 90W ×1）、云（Cloud ×15 / AI ×12）、100G（×9）全部已覆盖**。→ **凡引用本文的「0 款 2.5G」，必须限定为「#2/#3/#4/#146 四家」，不得推广为 A 档整体**；详见 `121` §一。


**这四家的自有交换机线，全部停在「GE + 1G SFP 上联 + af/at 30 W」，24 口有相当比例还是百兆。**
**2.5G / 802.3bt / 云管理 这四家里 0 家**（⚠ **仅指这四家**；`A/001` Telkolink 三项全有，见上框与 `121`）。
→ **这就是我方在 A 档的全部谈判空间，而且和 B 档（upTech/Cifocs）的结论完全一致** —— 说明**这是土耳其渠道的整体技术水位，不是某一家的问题**。

## 一、⭐⭐ 第二个价格锚点：Snexus 公开美元价（本文件最重要的一段）

`Snexus` 把**美元零售价**直接印在官网分类页（`Excluding GST/HST`）。这是全项目**第二个**公开价源，而且是**第一个「自有品牌 + 三层 + 10G」的美元价**。

| 型号 | 规格 | **公开价 USD** |
|---|---|---|
| `SN-GS2300-10F` | 网管千兆 8 口（L2） | **320** |
| `SN-GS2300-10FP` | 同上 + PoE | **400** |
| `SN-GS2300-28F` | 网管 24 口 GE（L2） | **660** |
| ⭐ `SN-GS2300-28FP` | **24 口 GE PoE（L2）** | **900** |
| `SN-XGS5300-28F` | L3 24×GE + **4×10G SFP+** | **1,130** |
| ⭐ `SN-XGS5300-28FP` | **L3 24×GE PoE + 4×10G** | **2,050** |
| `SN-XGS5300-52F` | L3 48×GE + 4×10G | **2,050** |
| ⭐ `SN-XGS5300-52FP` | **L3 48×GE PoE + 4×10G** | **2,750** |

### 这三档价怎么用

| 市场价 | 对应我方型号 | 建议报价位 |
|---|---|---|
| **$900** = 24 口 GE PoE **L2** | `EW-S2926GM-AP`（24 GE PoE + 4 Combo + 2 SFP，L2+） | **必须 < $900** |
| **$2,050** = 24 口 GE PoE **L3 + 4×10G** | `EW-S5748GM-AP`（**48** PoE L3 + 4×10G） | 落在 **$1,6xx** 就是「口数翻倍、价格低两成」 |
| **$2,750** = 48 口 GE PoE L3 | `EW-S5954GM-AP`（L3+ OSPF/VRRP） | 同上 |

⚠ **口径纪律**：这是**零售价**，不是 FOB。批发折扣按 **30–45%** 估；**不要拿它直接当我方成本上限**。

### A/003 Snexus · 7 段产品线
`Plug&Play Megabit PoE` → `Plug&Play Gigabit PoE` → `Plug&Play Gigabit`（`SN-GS1300-24`，24×GE 非网管）→ `Managed Gigabit`（`SN-GS2300`，L2）→ **`Managed 10G`（`SN-XGS5300`，L3，24/48 + 4×10G）** → `Fiber Backbone` → `Industrial`。
**缺口**：**无 2.5G、无 bt、非网管线只有 1 款**（8/16 口是空白）→ `EW-S1710FG-AP` / `EW-S1927CG-AP` 直接补。
