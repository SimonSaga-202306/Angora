- IETF 镜像 `fe367b60547788ed755be66dbec17e819f63c77c` 自标 commit 时间 2021-10-20 16:45:45 UTC。其直接父文件（同日 10:30:16 UTC 的 commit）对精确行 `58029` 与 `Angora Networks` 均零命中；子文件对应数字行紧接名称行。完整父子文件的 SHA-256、大小和 Git blob 与 Contents API 核验；本地 Git diff 的 hunks 与 commit API patch 相同。[父子分析](pen-ietf-parent-child-comparison-result.json)、[完整 diff](pen-ietf-parent-child-local.diff)、[16 个快照全文扫描](pen-full-scan-results.json)／[后四个快照](pen-ietf-full-scan-results.json)。
- 父子文件首部都标 `last updated 2021-10-20`，这是**全表**的自标更新日期；快照和 commit 时间不自动等于编号真正分配日期、申请时间或法人身份。镜像可能延迟、历史可能不全或记录被改写；在该镜像这一父子版本中新增此行，不等于首次在任何地方出现。此记录比 r114／r116 的实时页提供更早的可核时间锚，但其**精确分配日仍未证**。
- rfinnie 另有 2021-10-20 的父版本和 2021-10-27 版本：前者没有精确行，后者有同一行；[本地 diff](pen-parent-child-local.diff)和 API patch 一致。两仓不同日期的**相同文件字节**和共同 IANA 来源使这些资料是复制链，不是独立成交或资质证据。
- 16 个完整原文件合计 70,958,756 bytes，分别保存在 `github-raw/` 各自原相对路径中；两批完整扫描先预列，再逐文件读取 UTF-8 与 Git blob 校验。记录和正文内包含公开登记联系信息，仅作历史来源保存，不据此联系个人；不把 PEN 与 2019 MAC `/36` 混同。
