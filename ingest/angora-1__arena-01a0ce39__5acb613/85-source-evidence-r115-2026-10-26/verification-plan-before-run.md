# r115 本地验证计划（运行前）

仅验证本地一致性，不验证远端原件、人工转录忠实、证书、合同、获奖、事实真伪或日期校准。范围：

1. 对三个已列 inventory 的 159 个不同文件完整读字节／UTF-8，复算大小、SHA，核总数和 291,565 bytes；包括 P01 的明确不完整索引、失败、漂移、重复块、初稿，不声称是独立来源数。
2. 查 108 个事前计划和逐查询元数据一一对应、记录的 431 个结果和四个零结果；这些人工计数与选取 URL 不是完整工具结果。
3. 26 个选定锚的文件、字节哈希和锚文本；训练伙伴页／归档的选定段、e-Safe 候选行和结果段比较；对各回放块只分别读取，不生成拼接文件。
4. 交付文档相对链接目标存在，核心边界文字、P01 不完整声明、日期和不声称穷尽的限制存在；三处草稿只作计划中的单次替换。
5. 主档仅按字节核已知 52,157 字节前缀及 359 字节索引追加，不解码、显示或分析旧正文；同 boot 的可核时间段超过 600 秒；当前分支正确。
6. 运行辅助单测及上述检查，记录输出；任何失败保留日志、修复后重试，不把第一次失败静默改成成功。之后精确列暂存路径、检查 diff 空白，不广泛暂存。
