# 本地限定文字对照计划

预先限定以下本地人工转存，不打开原网站或图片；每对分别输出指定子串的出现次数、字节哈希和比较结果，不覆盖任一来源。

1. P01 与 AR04：比较议程日期、时段及 `Levent KILIÇ, _Angora Networks Kurucu Ortak_` 这三个短子串是否均出现；不比较整篇、不推断活动实际发言。
2. P02 与 AR05：只比较人物简介中“自 2016 年以来”的一句；即使本地转存字节一致，也不证明远端 HTML 或人物经历真实。
3. P05 与 AR06：只比较活动发生的第一句；即使字节一致，也不能证明 Angora 特定人员参加。
4. AR06 与 P05：仅对保存可见文本搜索 `Angora`／`Levent`，缺词不等于图片、音频、原 HTML 或全部报道不存在该人。

三份归档与其对应直连网页分别保存，但每对属于**同一来源的不同呈现或快照**，不是六个独立证人。以上回放的首块在分块数量未知时已取得；分块先读后组装，然后才预列汇总范围并回读，不能谎称所有范围在最初读取之前建立。
