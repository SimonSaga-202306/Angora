# r116 检索计划（检索前）

## 目标

继续以 Angora Networks 本体为中心，优先寻找 **2016–2022 早期公开业务及机构线索**：培训合作方自己的课程／活动证据、行业组织或学术／科技园区页面、可公开访问的公司注册主体信息、历史渠道及项目表述；以公开 GitHub 元数据／原文件作为可校验的补充。新近结果只用于必要交叉核对，不夸大穷尽。

## 程序与证据等级

- 每批查询、GitHub API 和候选取文／回放均先分别列计划；每个来源和每块单独保存，保持 URL 相对路径、页面名称及回放时间；多块不拼接。查找后先列完整本地限定范围，逐文件完整读取、记字节与 SHA-256；结果包含失败／重复等时不当作独立来源数量。
- 搜索摘要是发现线索，不替代全文。网页抓取只称工具可见文本的人工转存，若有分块必须取全；转存不声称原 HTML 或与工具原始输出自动逐字节相等。GitHub `gh api` 的 JSON 原响应或原始内容用独立文件保存并做哈希，可注明具体 commit/blob；仍不证明硬件实测、证书、合同或客户验收。
- 官网及第三方自述、组织方安排、媒体采访、归档捕获、工商官方登记、可执行合同、设备实测分别评级；主体不明即写“主体未确认”。重复主体仅指向已有记录、不合并来源、不新建重复客户。需要修正旧轮时，在本轮 dossier 独立附录及 mapping 中具名标明“修正／取代 rXX”，保留旧版。
- 优先以历史捕获和原始发布方判定时点。会话日期 2026-10-26 UTC 与沙箱墙钟观察到 2026-11-20 UTC 冲突，未校准；不能用墙钟覆盖会话日或倒填抓取时间。2026-10-26 是路径标签及有时的历史截止；比其晚的字段、动态侧栏、搜索混入的推荐不作已发生事实。
- 保留 INFO.rar、官网评论 reCAPTCHA、48 口澄清、阶梯报价、主动下载官网 PDF 数据表、历史财务差异、未成交／未付款旧单和仓库旧 RFQ/RFP 的永久 PASS；不访问 r104 PDF／r106 隔离关于页，不检索或主动接触用户已叫停主体、不追问不愿披露的 partner。KBYB 不承诺代拿证、不称特定要求必然违法、不把标识当作通过安全审查。
- C 档不跟进；重复主体只联系一次；本轮以被动公开研究为主，不发邮件、不登录设备或会议，不用关闭的 Gmail/Drive。没有新 Ewind 信息不改变既有对手分类。
- 目标工作时间至少 10 分钟，按同 boot ID 的单调时钟计时，包含研究、阅读、判断和等待，不睡眠凑时。
