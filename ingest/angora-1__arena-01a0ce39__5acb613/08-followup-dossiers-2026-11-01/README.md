## 一、筛选标准（为什么是这 21 家，不是别的）

同时满足下面任意两条才入选：

1. **有已发生的接触**（面见 / 来深圳 / 微信已通 / 已报价）—— 冷启动成本最低；
2. **有已核实的在用供应链可替换**（在卖 E-wind / 丰润达 / HRUI / 三旺 / Utepo / 光网视 等），替换路径明确；
3. **有自有品牌 + OEM 诉求**（贴牌一次成交=长期订单，不靠单次报价）；
4. **有订单级或项目级信号**（500 台量、政府项目、军项目、要样品、问交期）；
5. **规模足够**（分销网络 ≥1,000 家、年流水 ≥$8M、Perpa 批发位）。

被剔除的：MFD（西门子深度绑定，红灯）、Bimel（Ruijie+Planet 黄灯 / Cisco 红灯）、PNetworks / Longline（自己就是竞对，转竞对监控）、PavoTek / Kiracı（战略留档，非客户）、以及只剩邮箱的 B/C 级 46 家。

## 三、每个文件里有什么（固定八段）

1. **一句话结论** —— 值不值得跟、值多少
2. **身份卡** —— 表格：主体/城市/规模/自有品牌/场景/名单来源
3. **证据链** —— 每条带日期与出处（哪个文件哪一行），**区分「已独立核实」与「用户侧口述」**
4. **为什么现在跟** —— 钩子，按可执行性排序
5. **我方打法** —— 具体产品线 + 报价/贴牌口径
6. **联系人与渠道** —— 逐字抄录（电话/邮箱/微信/展会见过的具体人）
7. **风险与注意** —— 红灯、信任边界、别说什么
8. **下一步动作 + 待核问题** —— 可直接派活的 checklist

## 四、看这批档案时必须知道的三件事

1. **评分不是拍脑袋**：`我方评估(0-100)` 列来自 111 管线，是「双 AI 初筛 + 我方人工核实」后的综合分；本文件夹里的排序在综合分上做了**可执行性加权**（有现存接触 > 分数高但没接触过）。
2. **凡是「用户侧事实」都没有被独立核实**：例如 Telkolink「外观一般」、NOVA「CEO 到访过」——档案里都标了来源，对外沟通时不要当成第三方证据用。
3. **报价全部是历史口径**，不是本轮重新核过的价。含 DDP/关税的方案一律要重算。
