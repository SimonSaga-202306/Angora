# ATO 第 8 名册历史快照查询计划

为避免将动态现页当作任意历史时点，预列两个独立 Wayback CDX 索引 GET；分别检查 `www.atonet.org.tr` 与 `atonet.org.tr` 的 `KomiteListe?komiteKodu=8` 精确目标，返回 JSON、限制 HTTP 200 并查询至 `20261026`。这是一个明确的检索过滤上限，**不是用户设定的研究截止**，也不阻止保存来源的后续主张。不同主机、大小写、查询参数、其他时间及未收录页面均不包含。

索引可见结果只支持存在或未返回此筛选的候选捕获；捕获不自动证明页面表格、版本、目标或法人情况。若有候选，再先列回放 URL、查看权限与隐私，不预称已获原始 HTML；失败时分别留错。
