[P361|Heading 2] Overview
[P362|Normal] This chapter describes how to configure the switch to start the Web management function.
[P363|Heading 2] Manage network port IP address and gateway configuration
[P364|Normal] Before you can manage the switch through the Web, you need to configure the IP address and gateway of the management network port through the command line. E.g :
[P365|Terminal Display] Switch(config)# management ip address 10.13.33.153/21
Switch(config)# management route add gateway 10.13.39.254
[P366|Normal]  The default IP address is 192.168.0.1
[P367|Heading 2] User account and password configuration
[P368|Normal] The user account and password for WEB management need to be configured through the command line. E.g:
[P369|Terminal Display] Switch (config)#username admin privilege 4 password admin
[P370|Normal]  The default user and password is admin, admin
